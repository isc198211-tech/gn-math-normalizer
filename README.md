# GN Math Normalizer

An Obsidian plugin that normalizes LaTeX and Markdown copied from Gemini Notebook, helping you create clean and consistent mathematical notes.

## Features

- **Automatic paste normalization:** cleans and standardizes Markdown and LaTeX when pasting content.
- **LaTeX normalization on Enter:** detects and normalizes complete mathematical expressions when you press Enter.
- **Conservative automatic correction:** identifies certain LaTeX formatting issues while editing.
- **Note normalization:** normalizes the content of the active note when it is opened.
- **Manual commands:** provides commands to normalize selected text, the last pasted content, or clipboard content.
- **Code protection:** avoids modifying fenced code blocks and inline code.
- **Markdown preservation:** takes lists, blockquotes, callouts, and existing mathematical delimiters into account.

## Compatibility

- Obsidian 1.5.0 or later.
- Desktop only.

## Installation

The plugin is being prepared for submission to the Obsidian Community Plugins directory.

Until it is published, installation is intended for development and testing.

## Development

This project is developed to improve the workflow of transferring mathematical content from Gemini Notebook into Obsidian.
